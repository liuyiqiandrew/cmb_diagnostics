# Regression baselines

This directory is the home for golden files used in Phase 3+ regression
tests. Phase 2 only wires fixtures; there are no assertion tests here yet.

## Current baseline pointers (defined in `tests/conftest.py`)

- `golden_tf_bf` — `test/bf_tf.npy` — EE transfer function from `test/new_estimator_test.py` run with the filter-binned (FB) SO maps.
- `golden_tf_ml` — `test/ml_tf.npy` — same estimator run on the ML-solved SO maps.

Both files are ~1.3 KB and are tracked in git on the `refactor` branch.

## Regression test (Phase 5 gated)

The end-to-end TF regression lives at
`tests/integration/test_bf_tf_regression.py` and is marked
`@pytest.mark.slow`. It skips cleanly when any required artefact is missing
(mask, Planck maps, SO FB maps, `test/bf_tf.npy`), so the default test set is
safe to run anywhere. On Della the test loads `configs/iso_satp3.yaml`,
runs the new `Pipeline` through `estimate_tf_ee` for SO 90 and 150, and
compares `FitResult.values` against the golden columns.

**Golden file convention.** β = 1.6 is the canonical value for the new code
(read from `configs/*.yaml`). There is no V1-compat β toggle; see
[`docs/migration.md`](../../docs/migration.md#numerical-divergences-from-v1).
The golden is regenerated by the new `Pipeline` itself via
`scripts/regen_tf_golden.py` (one-shot, run manually on Della) so the
regression compares the pipeline to its own reproducible output rather than
to the V1 code. After regeneration the tolerance tightens to `rtol=1e-6`;
the transitional `rtol=5e-2` was a β = 1.53 → 1.6 ride-along and is removed
once the β = 1.6 golden lands.

Baselines should be regenerated and re-committed only when a scientifically
justified change to the estimator is intentional; document the reason in the
commit message and cite the generating commit SHA.
